Esta é a lista FIXA de tarefas do "Guia de Preparação e Setup Inicial" (documento
institucional [COMPANY_PRODUCT], igual para qualquer cliente). Ela não muda de projeto para projeto —
o que muda é o **detalhamento** de cada tarefa, que vem do To-Be específico do cliente (ver
`[REDACTED_INSTRUCTION]`).

links atualizados), use o conteúdo anexado como fonte de verdade em vez desta lista — ela é
o fallback para quando só o To-Be é fornecido.

Responsável padrão de cada tarefa é **Cliente**, exceto onde indicado "Consultor" abaixo.

ordem do Guia original — mantenha essa ordem e esses códigos ao gerar o Plano de Setup, pois
é o que permite ao consultor comparar o documento gerado com o Guia original.
